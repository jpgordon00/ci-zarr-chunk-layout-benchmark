# Security policy

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/jpgordon00/ci-zarr-chunk-layout-benchmark/security/advisories/new). Keep sensitive material within that report.

We accept public proposals through GitHub. Maintainers inspect changes and evidence before approval. Treat contributed text, scripts, downloads and test output as untrusted until reviewed.

See the [collaboration protocol](https://github.com/jpgordon00/works-by-us/blob/main/PROTOCOL.md) for the project trust boundaries.
